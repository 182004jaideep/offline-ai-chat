# Security Policy

## Reporting a vulnerability

If you find something that could:
- leak chat data or document content outside `127.0.0.1`,
- cause Normal-mode data to be written off the drive,
- cause Disappearing-mode data to be written anywhere at all, or
- defeat the drive-loss/corruption fail-safes,

please open an issue describing the problem. This project's entire value proposition is staying local and private, so reports like these get priority.

There's no bug bounty program and no dedicated security contact beyond the repository's own issue tracker — this is a personal, early-stage project, not a funded one.

## Supported versions

This project doesn't yet have tagged releases with a support policy; the `main` branch is the only supported version at this stage.
